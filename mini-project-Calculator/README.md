# Calculator Mini Project

## About the Project
I created a simple calculator using HTML, CSS, and JavaScript.  
The calculator can perform basic operations like addition, subtraction, multiplication, division, and percentage.

## Tutorial Reference
I followed a YouTube tutorial to understand how to build the calculator:  
https://youtu.be/p3FfcJN6lrE

## What I Did
I rebuilt the project myself instead of copying the code.  
I tried to keep the code like very simple and easy to understand.

## Improvement I Added
I added a **DEL button**.  
This button removes only the last entered value instead of clearing everything.  
It helps the user fix small mistakes easily.
