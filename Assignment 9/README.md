# Store Code Review

## Project Description
This project is a simple grocery store webpage where users can enter quantities of items, calculate total cost, and print a receipt. The cart resets automatically after inactivity.

## Professional Improvement

### Problem
The code repeats similar logic for each product, making it longer and harder to maintain.

### Why it matters
If more items are added, the code becomes messy and inefficient.

### Suggested Improvement
Use an array and loop to handle all items instead of repeating code.

## What I Learned
- How to understand existing code
- How HTML, CSS, and JavaScript connect
- How DOM manipulation works
- Importance of clean and maintainable code
